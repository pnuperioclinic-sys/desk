# 닥터배치과 · 데스크 응대 매뉴얼

데스크 실무자가 현장에서 바로 찾아볼 수 있도록 만든 응대 매뉴얼 웹페이지.
외부 라이브러리 없이 HTML 파일 한 장으로 동작합니다.

## 구성

- `desk.html` — 매뉴얼 전문 (HTML + CSS + JS 인라인)

## 목차

| # | 챕터 | 주요 내용 |
|---|------|-----------|
| 1 | 전화 응대 | 3:3:3 기법, 10대 원칙, 응대 도중 전화, 전화 예약, 상황별 NO→YES 표 |
| 2 | 접수 응대 | 접수자 태도, 접수/수납 타이밍, 신환 3유형, C.C 확인, 접수증, 대기 관리 |
| 3 | 치료 후 응대 | 종료 3단계, 치료비 문의 대응, 기억할 부분(Happy Call 포함) |
| 4 | 예약 | 효율적 예약관리 7원칙, 예약 시 응대, 확인 콜, BA/CA 대응 |
| 5 | 불만 환자 응대 | TARP 통계, 불만 원인, 화가 난 환자 응대, MTP 기법 |

## 기능

- **검색** — 상단 검색창에 키워드 입력 시 해당 항목만 필터링 + 하이라이트 (`/` 키로 검색창 포커스, `Esc`로 초기화)
- **목차 사이드바** — 데스크톱에서 현재 위치 자동 표시 (scroll spy)
- **인쇄 최적화** — `Ctrl+P` 시 챕터별 페이지 분할, 검색어와 무관하게 전문 출력
- **다크 모드** — 시스템 설정 자동 대응
- **모바일 반응형** — 표는 가로 스크롤 처리

## 보기

```bash
start desk.html      # Windows
```
